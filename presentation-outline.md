# TechNovation Pitch — Speaking Outline
15 min total | Ask: $3.18M, Executive Champion, profitable by month 21

---

## 1. Christopher (~4–4.5 min) — Tech & Value Prop

**Hook (45s)**
- 5 yrs decline, not product failure — pace of innovation
- Ask: $3.18M AI clinical decision support tool
- 6mo to existing clients, 12mo to new clients

**Tech Description (2 min)**
- Licensing/customizing **OpenEvidence** — live at Mount Sinai, Cedars-Sinai (Epic-integrated) — not building from scratch
- AI layer integrated into existing platform (not standalone)
- Clinician enters symptoms/history → cross-references cases + literature → suggests diagnoses, flags drug interactions, next steps
- Decision support, not replacement — clinician retains judgment
- Upgrade, not rip-and-replace → low adoption barrier

**Value Prop (1.5 min)**
- Fixes stated problems: slow innovation, customer dissatisfaction
- Client value: fewer errors, faster decisions, better outcomes
- Us: legacy vendor → modernization partner
- Competitors: still rules-based, not adaptive AI — window to leapfrog

**Transition:** → Margie, clinical + roadmap

---

## 2. Margie (~4 min) — Clinical Value + Project Plan

**Clinical Value (1.5 min)**
- Clinicians stretched thin, time pressure, errors cost money + trust
- No workflow change — tool sits inside existing process
- Low-friction adoption → existing client becomes reference for new sales

**Milestones (2.5 min)**
- **Mo 1–6 (Build):** OpenEvidence integration, data infra on existing **Azure** environment, compliance groundwork with **Clearwater** in parallel → demo ready
- **Mo 6–12 (Pilot):** 3–5 existing clients, clinical validation, feedback loop, Clearwater compliance sign-off → case studies + outcomes data
- **Mo 12+ (Expand):** broader existing-base rollout + new-client sales using pilot proof
- Logic: each phase produces evidence for the next

**Transition:** → Ashley, cost/ROI

---

## 3. Ashley (~4 min) — Funding & ROI

**Framing (30s)**
- $3.18M ask — every dollar traces to a named vendor or role/hour, not a round estimate

**Costs (1.5 min)**
- $1.16M — AI licensing/customization (**OpenEvidence**)
- $681K — integration engineering (internal + contract engineers)
- $498K — data infra & compliance (**Azure for Healthcare** + **Clearwater**)
- $607K — core leadership team (12 mo)
- $236K — pilot contingency (~8%)
- **Total: $3.18M**

**Revenue Model (2 min)**
- $150/provider/month, ~4,800 provider seats in existing base
- Mo 12: ~960 providers → $144K/mo
- Mo 18: ~3,120 providers → $468K/mo
- Mo 21: ~4,250 providers → ~$637.5K/mo — still under existing base, no new clients required
- Ongoing operating cost post-launch: ~$75K/mo (vendors + reduced support team)
- Profitability: cumulative revenue overtakes cumulative cost (build + ongoing) during month 21
- New clients (Mo 23–24): existing base saturates (~5,000–5,200 providers) — upside, not required for profitability

**Close (30s)**
- Own the internal adoption pace directly — ~20% to ~88% of existing base in 21 months is the assumption to stress-test, not new-client wins

**Transition:** → Dane, team/risk/close

---

## 4. Dane (~3–3.5 min) — Team, Risk, Champion, Ask

**Team (30s)**
- Christopher: technical | Margie: clinical/PM | Ashley: finance | Dane: client relationships
- Named partners where it beats in-house: **OpenEvidence** (AI), **Clearwater** (compliance)
- Hiring path built into later phases — team not overextended pre-revenue

**Risks & Mitigations (1.5 min)**
- **Clinician adoption** → pilot co-design, decision-support framing, physician has final call
- **Regulatory/compliance** → **Clearwater** engaged month 1, parallel to build, not bolted on
- **Integration complexity** → existing-platform clients only; extend existing **Azure** environment, not a new provider
- **Liability** → advisory tool only; built into contracts, training, messaging

**Executive Champion (1 min)**
- Profile: CMO or VP Clinical Innovation
- Role: clinician credibility, peer access to client leadership, internal advocate at mo 12–15 if ramp is slow

**Closing Ask (30s)**
- $3.18M / 12 months / named proven partners (OpenEvidence, Clearwater) / Executive Champion / profitable by month 21, driven by existing relationships not new business
- End: "fund the fastest, lowest-risk path back to leadership"
