# TechNovation Pitch — Speaking Outline
15 min total | Ask: $3.8M, Executive Champion, 18–24mo to break-even
 
---
 
## 1. Christopher (~4–4.5 min) — Tech & Value Prop
 
**Hook (45s)**
- 5 yrs decline, not product failure — pace of innovation
- Ask: $3.8M AI clinical decision support tool
- 6mo to existing clients, 12mo to new clients
**Tech Description (2 min)**
- AI layer integrated into existing platform (not standalone)
- Clinician enters symptoms/history → cross-references cases + literature → suggests diagnoses, flags drug interactions, next steps
- Decision support, not replacement — clinician retains judgment
- Upgrade, not rip-and-replace → low adoption barrier
**Value Prop (1.5 min)**
- Fixes stated problems: slow innovation, customer dissatisfaction
- Client value: fewer errors, faster decisions, better outcomes
- Us: legacy vendor → modernization partner
- Competitors: still rules-based, not adaptive AI — window to leapfrog
**Transition:** → Margie, clinical + roadmap
 
---
 
## 2. Margie (~4 min) — Clinical Value + Project Plan
 
**Clinical Value (1.5 min)**
- Clinicians stretched thin, time pressure, errors cost money + trust
- No workflow change — tool sits inside existing process
- Low-friction adoption → existing client becomes reference for new sales
**Milestones (2.5 min)**
- **Mo 1–6 (Build):** AI integration, data infra, compliance groundwork in parallel → demo ready
- **Mo 6–12 (Pilot):** 3–5 existing clients, clinical validation, feedback loop, compliance sign-off → case studies + outcomes data
- **Mo 12+ (Expand):** broader existing-base rollout + new-client sales using pilot proof
- Logic: each phase produces evidence for the next
**Transition:** → Ashley, cost/ROI
 
---
 
## 3. Ashley (~4 min) — Funding & ROI
 
**Framing (30s)**
- $3.8M ask — phase-one investment, not full vision
**Costs (1.5 min)**
- $1.2M — AI licensing/customization
- $700K — integration engineering
- $500K — data infra & compliance
- $1.1M — core team (12 mo)
- $300K — pilot contingency
- **Total: $3.8M**
**Revenue Model (1.5 min)**
- $150/provider/month, ~3,000 provider seats in existing base
- Mo 12: ~450 providers → $67.5K/mo
- Mo 18: ~1,400 providers → $210K/mo
- Mo 24: ~2,200 providers → $330K/mo
- Break-even: cumulative revenue > cumulative cost by mo 20–22
**Close (30s)**
- Defensible, not impressive — conservative model, not best-case
**Transition:** → Dane, team/risk/close
 
---
 
## 4. Dane (~3–3.5 min) — Team, Risk, Champion, Ask
 
**Team (30s)**
- Christopher: technical | Margie: clinical/PM | Ashley: finance | Dane: client relationships
- Hiring path built into later phases — team not overextended pre-revenue
**Risks & Mitigations (1.5 min)**
- **Clinician adoption** → pilot co-design, decision-support framing, physician has final call
- **Regulatory/compliance** → addressed month 1, parallel to build, not bolted on
- **Integration complexity** → start with existing-platform clients only
- **Liability** → advisory tool only; built into contracts, training, messaging
**Executive Champion (1 min)**
- Profile: CMO or VP Clinical Innovation
- Role: clinician credibility, peer access to client leadership, internal advocate at mo 12–15 if ramp is slow
**Closing Ask (30s)**
- $3.8M / 12 months / Executive Champion / 18–24mo to prove pace-setting, not just position-protecting
- End: "fund the fastest, lowest-risk path back to leadership"
